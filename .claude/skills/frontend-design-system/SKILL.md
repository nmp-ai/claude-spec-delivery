# Frontend design system

## When generating UI

- Use predefined spacing scale (4, 8, 12, 16...)
- Use semantic color tokens (primary, secondary, error)
- Prefer existing components over raw HTML
- Follow consistent typography

## Never

- Hardcode colors
- Mix design patterns

## If missing

- Suggest reusable component instead
